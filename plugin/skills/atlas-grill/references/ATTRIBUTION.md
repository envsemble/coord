The interview and domain-modeling resources derive from Matt Pocock's [skills repository](https://github.com/mattpocock/skills), under the [MIT license](LICENSE), copyright (c) 2026 Matt Pocock. The full upstream license notice is retained beside these resources; the primary [upstream LICENSE](https://github.com/mattpocock/skills/blob/main/LICENSE) was verified on 2026-10-06.

The authoring inputs were installed `CONTEXT.md`-based variants supplied for this rework, rather than a replacement with newer upstream naming conventions:

- Its [ADR-FORMAT.md](https://github.com/mattpocock/skills/blob/main/skills/engineering/domain-modeling/ADR-FORMAT.md) → [ADR-FORMAT.md](ADR-FORMAT.md)
- [Grill with docs](https://github.com/mattpocock/skills/blob/main/skills/engineering/grill-with-docs/SKILL.md) supplied the composition idea; its unavailable `Skill`-tool wrapper is replaced with direct reading of the bundled methods. The [atlas-grill](../SKILL.md) skill, which keeps these resources, is that composition: the explicit start, rounds over the design tree, recording as answers settle and the end with the plan ready to accept, with the planning folder found and work items changed through the Atlas tools.

The design tree, independent frontier rounds, recommendations, waiting for decisions, factual investigation, glossary challenges, concrete scenarios, code contradictions, immediate term recording, glossary-only rule, three-condition ADR threshold, concise formats, and meaningful optional ADR additions are preserved substantively. Adaptations route work-specific records and every embedded map/path example into the selected work item, preserve canonical product docs and archive originals, use tools or useful authorized delegation for facts, and respect already settled understanding and direct coding authorization. Interface frontmatter is replaced by the new skill entry point; no original unavailable invocation mechanism is required.
